### 👋 Sobre mim

Desenvolvedor focado na criação de aplicações web modernas, sistemas SaaS, automações e utilitários de performance. Experiência prática desenvolvendo soluções completas — do banco de dados à interface responsiva.

- 🚀 Fundador da **TheOneHub** — desenvolvimento de plataformas web, catálogos digitais e sistemas sob medida
- 💻 Foco principal em **TypeScript, React, Next.js, Node.js** e bancos relacionais/NoSQL
- ⚙️ Experiência adicional com **C#, C++, Python** e programação de robôs industriais
